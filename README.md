## About This Repository

This repository contains my digital humanities portfolio, weekly creative makes, critical reflections, and academic Curriculum Vitae for **DH 101: Introduction to Digital Humanities** at Denison University.

### Key Sections
- 📄 **[Curriculum Vitae](https://kateng.github.io/DH101/pages/cv.html)** — Academic background, digital humanities methods, technical skills, and research experience.
- 🛠️ **[Weekly Makes](https://kateng.github.io/DH101/makes/)** — Thirteen experimental digital artifacts exploring reverse engineering, remix culture, text analysis, and AI futures.
- ✍️ **[Weekly Reflections](https://kateng.github.io/DH101/reflections/)** — Weekly writings on the ethical, ecological, and cultural implications of technology and AI.
- 👤 **[About Me](https://kateng.github.io/DH101/pages/about.html)** — Research interests and scholarly goals.
- 📖 **[Markdown Guide](https://kateng.github.io/DH101/pages/markdown-guide.html)** — Formatting reference and reflection templates.

## GitHub Pages Deployment

To enable or verify the live website on GitHub:
1. Go to **Settings** > **Pages** in this GitHub repository (`KateNg/DH101`).
2. Under **Build and deployment**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
3. Save changes. GitHub Pages will build and publish your site at `https://kateng.github.io/DH101/`.
